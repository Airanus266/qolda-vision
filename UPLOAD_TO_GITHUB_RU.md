# Как загрузить проект

1. Распакуй ZIP. Открой папку `qolda-vision`.
2. Создай публичный репозиторий GitHub с именем `qolda-vision`. Если загружаешь файлы из этого архива, отдельный пустой README создавать не нужно.
3. Нажми **uploading an existing file** (в пустом репозитории) или **Add file → Upload files**.
4. Перетащи **содержимое** папки: README.md, dist, docs, scripts, tests, package.json и остальные файлы. Сам ZIP загружать вместо исходников не нужно.
5. Сохрани коммит с сообщением `Add QOLDA Vision research prototype`.
6. Проверь, что файл `.github/workflows/quality.yml` тоже попал в репозиторий. Если Проводник не показывает скрытые элементы, включи их отображение.
7. Во вкладке Actions дождись результата проверок. Их успешный локальный запуск не означает, что GitHub Actions уже выполнился.

Название для заявки: **QOLDA Vision — Camera-Based Hand Motion Analysis and Gesture Learning**.

Для проверки на Windows установи Python 3, если его нет, и запусти START_WINDOWS.bat. Открой http://localhost:8000. Для тестов нужен Node.js 20+.

Приватное демо из предыдущего сообщения показывает предыдущую версию 0.1; этот архив содержит 0.2. Публикация на GitHub сама по себе не включает веб-хостинг. Для статического хостинга точкой публикации служит папка dist.

Перед подачей проверь реальную камеру, собери примеры и прочитай README. Будь готов объяснить, что MediaPipe — готовая модель, а собственный эксперимент использует геометрические признаки и kNN. В README отмечена помощь ИИ при реализации; указывай свой вклад точно.
